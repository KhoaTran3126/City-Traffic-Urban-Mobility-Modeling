# Dashboards

This directory contains interactive dashboards developed to communicate key findings from the **City Traffic & Urban Mobility** analysis.

The dashboards transform analytical results into concise visual narratives, highlighting temporal traffic patterns, demand intensity, and other urban mobility dynamics.

## Contents

- **Traffic Demand & Temporal Mobility** — Explores hourly traffic demand, city-zone differences, peak periods, and the distribution of traffic across the daily cycle.

Each dashboard folder include the packaged Tableau workbook (`.twbx`) and a static preview (`.png`) for convenient viewing on GitHub.
